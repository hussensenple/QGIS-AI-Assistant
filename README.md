# 🐍 QGIS PyQGIS Assistant

This is an AI-powered GIS Assistant built with Streamlit and Gemini 2.5 Flash. It specializes in generating modern PyQGIS scripts for repetitive tasks.

## Setup
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Add your Gemini API Key in the app sidebar.
4. Run the app: `streamlit run app.py`
